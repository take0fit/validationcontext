# Product Overview

ValidationContext は、Go アプリケーションで分散しやすいバリデーション処理を 1 つのコンテキストに集約するためのライブラリです。特に構造体変換時に、複数入力項目の検証エラーを遅延収集し、ユースケース層で一括ハンドリングできることを目的とします。

利用者は主に Go のバックエンド開発者で、レイヤーを問わない構造体変換時に「全項目のエラーをまとめて返したい」ケースを対象とします。

## Core Capabilities

- 複数フィールドの検証エラー収集（`ValidationContext`）
- 検証エラーの整形・集約（`FormatErrors`, `AggregateError`）
- 文字列・数値・日時・ネットワーク・ファイル検証の標準メソッド提供
- スタックトレース付きエラー情報保持
- `voauto` によるレイヤー非依存な構造体間バインドと検証
- `voauto-gen` によるコンストラクタ登録コード自動生成

## Target Use Cases

- 複数構造体をまたぐ入力検証を一括で扱う
- API リクエストの不正入力をフィールド単位で収集して返却する
- ドメイン層のコンストラクタ実行を統一パターンで自動化する
- バリデーション実装の重複コードを減らし、テスト容易性を上げる

## Value Proposition

- 検証ロジックの分散と重複を抑えつつ、エラー返却を一元化できる
- 実装者が個別にエラー連結を書く必要がなくなる
- 既存 Go コードへ段階導入しやすい（追加依存が少ない）
- `go:generate` ベースで構造体バインドを半自動化できる
